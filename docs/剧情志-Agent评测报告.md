## 三、未满分用例归因

### E05 · 0.80 · 「鸣潮的玄翎谣是什么？」

- 期望工具 `search_story` / 实际 `search_story`：**工具选择正确，无缺失**。
- 关键词命中：✅（答出了「玄翎雀」及其相关剧情）。
- 扣分点在「拒答行为」：模型回答「剧情知识库中**未**检索到玄翎谣」——命中了打分器的
  否定词正则（`知识库(中)?(没有|未)`），被记为「不该拒答却拒答」，扣 0.2。
- **人工复核结论：这是打分器口径问题，不是 Agent 失误。** 「玄翎谣」确实不在本地语料中，
  模型的做法恰是期望行为——先如实说明没查到，再主动给出最接近的真实词条（玄翎雀）
  并标注「可能是别称、误记」，**没有编造一个不存在的剧情**。
- 这条用例暴露的是评测集标注问题（该题把「近似词」当成了「库内词」），已列入已知局限。

## 四、已知局限

- 评测集为项目自建（18 题），覆盖面有限，不构成通用 benchmark。
- 关键词命中采用「命中任一」的宽松判定，同义改写可能被误判为命中。
- 拒答判定基于否定词正则，未做人工复核（E05 即受此影响，见上文归因）。
- 单次运行结果受模型采样随机性影响；kimi-k2.x 被强制 temperature=1，波动更大。
- 平均耗时含主动限速等待：RPM=3 下每题 2~3 次模型调用需按窗口排队，
  该数字反映的是「低配额环境下的真实体验」，不代表模型本身的推理延迟。
